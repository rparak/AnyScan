RP file header — two forms. Use whichever the HOST REPOSITORY already uses and
copy that block into the new file, fixing the `File Name:` line to the real
path. Consistency within the repo wins: do not introduce a second header form.

  - The source repository (RoLE) writes the header as a `"""` docstring
    (Form A). The .py templates in this directory default to it.
  - A repository whose files open with a `#`-comment block (e.g. anyscan-pyqt)
    keeps that form (Form B).

Delete this note and the form you did not use.
